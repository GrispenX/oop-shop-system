# User Guide - ATP Management System

## Запуск

див. README

```bash
./build/src/ATP
```

Після запуску відкриється головне меню з наступними опціями:

1. Products - керування товарами
2. Receitps - керування чеками
3. Cashback & customers - керування покупцями
4. Quit - вихід з програми

## Products

### Перегляд списку товарів

- В меню Products виберіть List products

### Створення товару

- В меню Products виберіть Add product
- Введіть назву товару
- Введіть ціну за одиницю товару (має бути більше за 0)

### Редагування товару

- В меню Products виберіть Edit product
- Введіть ID товару (можна знайти в списку товарів)
- Виберіть поле яке хочете змінити (назва, ціна, поповнити наявність, встановити/зняти знижку)

## Cashback & customers

### Перегляд списку покупців

- В меню Cashback & customers виберіть List customers

### Додавання покупця

- В меню Cashback & customers виберіть Add customer
- Введіть ім'я покупця
- Введіть прізвище покупця

### Редагування покупця

- В меню Cashback & customers виберіть Edit customer
- Введіть ID покупця (можна знайти в списку покупців)
- Виберіть поле яке хочете змінити (ім'я, прізвище)

## Receipts

### Список чеків

- В меню Receipts виберіть List receipts

### Створення чеку

- В меню Receipts виберіть New receipt

Відразу відкриється меню редагування цього чеку

### Додавання товару

- В меню редагування чеку виберіть Add item
- Введіть ID товару (можна знайти в списку товарів)
- Введіть кількість (має бути більше 0)

### Скасування чеку

- В меню редагування чеку виберіть Cancel receipt

Вже додані товари автоматично з'являться в наявності.

### Додавання покупця до чеку

- В меню редагування чеку виберіть Set customer
- Введіть ID покупця (можна знайти в списку покупців)

### Закриття чеку

- В меню редагування чеку виберіть Close receipt
- Якщо ви додали покупця, введіть кількість кешбеку, який бажаєте використати.
- Після закриття автоматично нараховується кешбек.

### Детальний перегляд чеку

- В меню Receipts виберіть View receipt details
- Якщо чек ще не закритий, відкриється меню редагування чеку
