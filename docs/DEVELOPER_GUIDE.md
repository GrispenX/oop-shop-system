# Developer Guide - ATP Management System

## Архітектура проєкту

Проєкт складається з 4 шарів: Core, Bussiness, Infrastructure, Console.

Патерни: Repository, FSM, Strategy.

## Правила розширення

Для створення нового виду знижки створіть клас, який наслідує IDiscountStrategy, додайте її в UI.

Для використання нового сервісу в UI додайте його в структуру Context (IView.h)

Дотримуватись RAII

Після розширення обов'язково запускати тести, новий функціонал також має покриватись тестами.

## Code style

Назви класів і структур пишуться camel-case'ом. назви приватних полів в класах пишуться також camel-case'ом з префіксом m_. Методи класів також пишуться camel-case'ом. Публічні поля та змінні в функціях пишуться snake-case'ом. Замість `#pragma once` використовувати include guards.
