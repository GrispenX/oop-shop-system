# Iteration 3 - ATP Management System

Оновлено та створено нові тести.

Загальна кількість тестів: 70

Змінено репозиторії, замінено тип методів Get на std::optional, замість кидання вийнятків. Оновлено сервіси для дотримання нового контракту. Старий контракт був гіршим, оскільки вийнятки які кидались на рівні репозиторіїв могли пролітати декілька шарів до try-catch блоку, що ускладнює розуміння архітектури.
