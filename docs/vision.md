# Vision - ATP Management System

## Призначення

CLI застосунок для керування магазинок. Він має надавати можливість для:

- Створення, редагування та перегляду товарів, встановлення різних видів знижок для них

- Створення чеків, додавання до них товарів, обрахуноку суми в процесі їх створення

- Система кешбеків, відсоток від чеку нараховується як кешбек, який можна використати для наступних чеків.

- збирання статистики по кількості проданих товарів, загальній виручці

## Цільові користувачі

Власники магазину

## Сценарії використання

- Створення, редагування та перегляд товарів

- Встановлення та зняття знижок з товарів

- Створення чеків(покупок) з обрахунком загальної вартості в процесі створення та використанням кешбеку

- Збір і перегляд статистики за період (день, тиждень, місяць, квартал)
