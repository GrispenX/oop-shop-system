# Vision

## Назва

ATP Management System

## Призначення

Цей проєкт призначений для керування магазином, включаючи керування товарами, знижками, чеками(покупками)

## Цільові користувачі

Власники магазину

## Сценарії використання

- Створення, редагування та перегляд товарів

- Встановлення та зняття знижок з товарів

- Створення чеків(покупок) з обрахунком загальної вартості в процесі створення
