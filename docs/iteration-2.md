# Iteration 2 - ATP Management System

Повністю готове керування товарами та чеками. Можна створювати та редагувати товари, керувати їх наявністю, встановлювати на них знижки. При додаванні товару до чеку кількість на складі автоматично зменшується, при відміні чеку збільшується.

В процесі цієї ітерації додалися інтерфейси для сервісів (IProductService, IReceiptService), з'явився новий репозиторій IInventoryStorage для збереження наявності, він додався до ProductService як залежність. ReceiptService тепер залежить від IProductService для зміни наявності при продажу.

InMem репозиторії змінились JSONStorage'ами. Додато JSONProductSerializer та JSONReceiptSerializer.
